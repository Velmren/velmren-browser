# Работа с Velmren

[English](USING-VELMREN.md) · [Установка и диагностика](SECOND-PC-RU.md)

## Поиск

Откройте меню справа вверху → **Настройки → Поисковая система**. Выберите поисковик для обычного окна; приватные окна имеют отдельную настройку. Новые обычные вкладки и адресная строка используют этот выбор.

Значок рядом с центральным полем новой вкладки позволяет выбрать другой поисковик для этой вкладки. В меню указано, какой поисковик выбран по умолчанию в браузере. Флажки в настройке списка добавляют или скрывают варианты меню; общий поисковик меняется в настройках браузера.

## Сохранённые аккаунты

После выбора аккаунта на сайте проверьте логин в подсказке пароля. Если для сайта сохранено несколько аккаунтов, можно явно выбрать другую запись из списка. Пароль относится к логину, указанному в этой записи.

Если выбранного аккаунта нет среди сохранённых записей, воспользуйтесь его собственными данными для входа. Сообщая об ошибке автозаполнения, укажите сайт и шаг входа; пароль и код подтверждения для диагностики не нужны.

## Вкладки и сохранённые страницы

- Чтобы вернуть закрытую вкладку, нажмите **Ctrl+Shift+T** или откройте контекстное меню вкладки → **Открыть закрытую вкладку**.
- **Закрепить** в контекстном меню вкладки оставляет компактную вкладку слева. Для нескольких страниц можно создать группу вкладок.
- **Закладка** сохраняет постоянную ссылку. Нажмите значок закладки рядом с адресной строкой и выберите имя и папку. Найти её можно на панели закладок или в меню закладок.
- **Список для чтения** удобен для страниц, которые нужно прочитать позже: в нём можно отмечать прочитанное. Он доступен среди боковых инструментов.
- Боковая полоса инструментов и открытая панель — разные элементы. Полосу можно выключить, а содержимое открытой панели закрыть её кнопкой **Закрыть**.

## Обновления

Когда обновление доступно, кнопка меню в шапке показывает его состояние. Нажмите её и откройте сведения об обновлении. Эта же информация доступна в **Настройки → О Velmren**.

Кнопка **Проверить обновления** запрашивает свежую проверку. Страница показывает результат последней проверки, доступную версию и стадии загрузки/подготовки. Во время загрузки можно продолжать работу.

Когда пакет готов, доступен **Перезапустить для обновления**. Обычные вкладки восстанавливаются штатным механизмом браузера. Приватные вкладки после перезапуска не восстанавливаются. Если кнопка недоступна из-за другой сессии или фоновых задач Velmren, сначала завершите эту работу.

При ошибке подключения повторите проверку после восстановления сети. Если обновление не удалось применить, текущая установленная версия остаётся доступной; используйте [инструкцию диагностики](SECOND-PC-RU.md) и сохраните точный текст сообщения.

## Рабочий профиль и запуск

Используйте обычный ярлык Velmren из меню «Пуск», рабочего стола или исправленного закрепления. Стабильный запускатель в папке установки сохраняет выбор профиля при обновлениях.

Если браузер внезапно выглядит пустым, проверьте способ запуска и выбранный профиль. Для диагностики достаточно пути ярлыка и номера версии из **О Velmren**; переносить или удалять профиль для этой проверки не требуется.
