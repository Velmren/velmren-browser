# Using Velmren

[Русский](USING-VELMREN-RU.md) · [Installation and diagnostics](SECOND-PC-RU.md)

## Search

Open the top-right menu → **Settings → Search engine**. Choose the normal-window search engine; private windows have a separate choice. New normal tabs and the address bar use that default.

The icon beside the new-tab search field lets you choose a different provider for that tab. The menu identifies the browser default. Checkboxes customize which alternatives appear in this menu; browser-wide changes belong in Settings.

## Saved accounts

After choosing an account on a website, check the username in the password suggestion. If several accounts are saved for that site, you can explicitly select another entry. Each saved password belongs to the username shown in its entry.

If the chosen account is not saved, use its own sign-in details. When reporting an autofill issue, include the site and sign-in step; passwords and verification codes are not needed for diagnosis.

## Tabs and saved pages

- Press **Ctrl+Shift+T**, or use a tab's context menu → **Reopen closed tab**, to recover a closed tab.
- **Pin** keeps a compact tab at the left of the tab strip. Tab groups help organize several pages.
- **Bookmarks** keep permanent links. Use the bookmark icon beside the address bar, then choose a name and folder. Find the page through the bookmarks bar or bookmarks menu.
- **Reading list** is for pages to read later and lets you mark items as read. Find it among the sidebar tools.
- The sidebar tool rail and an open content panel are separate. Turn off the rail and use the panel's **Close** button to close its content.

## Updates

When an update is available, the menu button in the browser header shows its state. Open it to view update details. The same information is in **Settings → About Velmren**.

**Check for updates** requests a fresh check. The page shows the last check, available version, and download/preparation stages. You can continue browsing while an update downloads.

When the package is ready, choose **Restart to update**. Normal tabs reopen through the browser's session mechanism. Private tabs do not reopen. If another Velmren session or background task blocks restart, finish that work first.

After a connection error, try again when the connection returns. If an update cannot be applied, the committed version remains available; follow the [diagnostic instructions](SECOND-PC-RU.md) and keep the exact message.

## Profiles and launch shortcuts

Use the ordinary Velmren shortcut in Start, on the desktop, or the repaired taskbar pin. The stable launcher in the installation directory preserves profile routing across updates.

If the browser unexpectedly looks empty, check the launch shortcut and selected profile. The shortcut path and version from **About Velmren** are useful diagnostic information; this check does not require moving or deleting your profile.
